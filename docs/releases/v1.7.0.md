# v1.7.0

> **Rocky Linux 10 update, 20 November 2026:** Rocky now provides
> `2:1.26.3-16.el10_3.1.0.1` through its opt-in `security` repository. Its
> changelog contains the five core nginx2root fixes but not CVE-2026-123640,
> CVE-2026-120967, CVE-2026-118899, or CVE-2026-125283. The complete v1.7.0
> `...0.1.hp1` package therefore intentionally remains newer. Do not downgrade
> or `distro-sync` NGINX until Rocky publishes a complete replacement.

This release adds separate native RHEL 10 and Rocky Linux 10 hotfix bundles and
reissues the native Oracle Linux 10 bundle alongside them.

At publication, RHEL 10 and Rocky Linux 10 shipped
`2:1.26.3-16.el10_3.1`. That package was released before nginx2root and does not
contain the November 18 NGINX fixes. See the Rocky Linux update above for its
later partial security-repository package.
The hotfix release `2:1.26.3-16.el10_3.1.0.1.hp1` remains below the next vendor
`.2` update. Oracle Linux 10 uses its separate
`2:1.26.3-6.0.1.el10_2.7.0.1.hp1` package lineage.

Every bundle is built from that vendor's exact pinned SRPM. The installers
reject another vendor, release, package lineage, or architecture. Package
changelogs name every included CVE, and runtime validation covers HTTP/1.1,
HTTP/2, reverse proxying, mail, stream, representative dynamic modules, ABI,
and fresh worker processes.
