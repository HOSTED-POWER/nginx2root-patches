# v1.3.2: CVE-visible package changelogs

This release replaces `hp2` with `hp3` packages whose native Debian and RPM
changelogs explicitly enumerate every CVE included in that platform build.
Package-content tests now fail if any selected CVE is absent from
`changelog.Debian.gz` or RPM `%changelog` metadata.

The security patches are unchanged from `v1.3.1`. The revision bump is required
because package repositories and installed systems must never reuse an existing
version for different package bytes. Version ordering remains:

```text
vendor base < hp1 < hp2 < hp3 < next vendor update
```

All Debian 8-13, CentOS 7 EPEL, and CentOS 8 AppStream packages retain their
existing package layout, dynamic-module ABI, and stream/modularity identity.
