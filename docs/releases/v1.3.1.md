# v1.3.1: complete applicable NGINX security backports

This release replaces the earlier `hp1` package builds with `hp2` packages and
adds every additional NGINX 1.30.7 fix applicable to each supported source tree.
Normal package upgrades prefer `hp2`, while future distribution updates still
sort higher and take over automatically.

## Added fixes

- CVE-2026-118899: request-body `NGX_AGAIN` handling.
- CVE-2026-120967: stream SNI-selected client-certificate verification, where applicable.
- CVE-2026-123640: strict `ssl_preread` ClientHello extension parsing.
- CVE-2026-125283: generated `try_files` path length handling.
- CVE-2026-123633 on the old CentOS 8 1.14, 1.16, and 1.18 streams.
- Debian 12 also receives CVE-2026-15176, CVE-2026-93479,
  CVE-2026-97205, and additional CVE-2023-44487 hardening from Debian's
  Bookworm security work-in-progress branch.

## Validation

Every package family is built from its exact pinned vendor source package in a
matching clean container. Upgrade tests preserve package layout, installed
module set, dynamic-module ABI, and CentOS modularity identity. Runtime tests
run `nginx -t`, start two fresh workers, and exercise HTTP/1.1, HTTP/2, reverse
proxying, mail, stream, and representative packaged dynamic modules.

Supported bundles remain Debian 8-13 amd64, CentOS 7 EPEL x86-64, and CentOS 8
AppStream 1.14, 1.16, 1.18, and 1.20 x86-64.
